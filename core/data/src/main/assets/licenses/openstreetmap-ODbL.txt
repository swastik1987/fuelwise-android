Fuel and charging station data

The station list bundled with this app (assets/stations/india.tsv.gz) is derived from OpenStreetMap.

© OpenStreetMap contributors
https://www.openstreetmap.org/copyright

The data is made available under the Open Database License (ODbL) 1.0:
https://opendatacommons.org/licenses/odbl/1-0/

The derived file keeps only each station's position, brand, name and the fuels it sells. It is published under the
same licence. It was extracted with the Overpass API; the extraction tool is tools/stations in the source repository.
